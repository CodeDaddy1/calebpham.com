# Security

calebpham.com is a static portfolio: no accounts, no forms, no server code,
no database. What it serves is HTML, CSS, JavaScript, images, video and one
PDF, from one origin, behind the headers described in `docs/security.md`.

## Reporting a problem

Email caleb@lumaiq.dev with the URL, what you did, what you saw, and what you
expected. A working example is worth more than a scanner's line. You will
have a reply within seven days. There is no bounty.

## In scope

Anything served from calebpham.com, and this repository.

## Out of scope

Vercel's platform, lumaiq.dev (it has its own process), and scanner output
with no working proof.

The machine-readable version is at
https://calebpham.com/.well-known/security.txt (RFC 9116).
